# Капитал

Личный учёт денег: баланс по картам и крипте в рублях и долларах, доходы и расходы, цели в долларах, прогноз месяца. Данные хранятся в Supabase и видны только владельцу аккаунта.

## Настройка (один раз)

1. Зарегистрируйся на [supabase.com](https://supabase.com) и создай проект (тариф Free).
2. **SQL Editor → New query** → вставь содержимое `supabase.sql` → **Run**.
3. **Authentication → Sign In / Providers → Email**: выключи «Confirm email», чтобы войти сразу без письма.
4. **Project Settings → API**: скопируй `Project URL` и ключ `anon public` в `config.js`.
5. Открой сайт, нажми «Создать аккаунт» и войди.
6. После этого в **Authentication → Sign In / Providers** выключи «Allow new users to sign up», чтобы никто больше не смог зарегистрироваться.

Ключ `anon` публичный по задумке Supabase: доступ к данным закрыт правилами в `supabase.sql`, каждая запись видна только своему владельцу.

## Перенос данных

Настройки (шестерёнка) → «Загрузить из копии» → выбери файл резервной копии `.json`.

## Курсы

Курс доллара (ЦБ РФ) и цены крипты (CoinGecko) обновляются автоматически при первом открытии сайта за день.
